A make.fun entry for the "Worst Fix Ever: Funniest Commit Message" bounty.
The program writes one commit message line — a bug fix that made everything
worse — to `/output/entry.txt`.

## The entry

```
fix: stop duplicate charges by charging everyone twice so nobody feels singled out
```

## Run

Requires Node 22 or later (TypeScript runs as-is):

```sh
node main.ts
```

It writes the line above to `/output/entry.txt`, deterministically.
